# Ask the Record

Short teaching exercises on one question: is an AI agent's record whole, and can someone outside check it?

- index.html: six seats (user, company, engineer, regulator, insurer, auditor), about two minutes each.
- find-the-gap.html: three rounds on spotting a missing entry, about five minutes.

Each exercise links to its public source. The cases are invented unless a source is named. These are not a product, a certificate, evidence or advice. Finding no gap never proves that nothing is missing.

Static pages. No tracking, no cookies, no network calls. All text sits in one STR block near the top of each file, so it can be translated by changing values only.
